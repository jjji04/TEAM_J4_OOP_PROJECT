# 테스트 계획 (아직 미실행)

| 항목 | 예상 결과 | 상태 |
|---|---|---|
| 영화 등록 및 조회 | 등록한 영화가 목록에 표시됨 | 미실행 |
| 상영회차 선택 | 선택한 영화의 상영 정보 표시 | 미실행 |
| 좌석 예약 | 예약 가능한 좌석 선택 및 저장 | 미실행 |
| 중복 예약 | 같은 회차·좌석의 중복 예약 방지 | 미실행 |
| 예약 취소 | 취소한 좌석이 다시 예약 가능 | 미실행 |
| 할인 계산 | 정책에 따라 최종 요금 계산 | 미실행 |
| 회원 로그인 | 올바른 계정으로 로그인 | 미실행 |
| 데이터 저장 | 프로그램 재실행 후 저장된 데이터 유지 | 미실행 |
